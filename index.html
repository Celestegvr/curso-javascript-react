Parte 1

Instalación de herramientas necesarias

Antes de programar se prepara el entorno: un editor de código con extensiones útiles y Node.js para trabajar con React.

1

Instalar Visual Studio Code

El editor que se usa durante todo el curso

Visual Studio Code (VS Code) es uno de los editores más populares para desarrollo de software. Trae IntelliSense (autocompletado según el framework), herramientas de depuración y una terminal integrada para ejecutar comandos, por ejemplo de Git.

  1. Busca vs code en Google y entra a la página oficial: code.visualstudio.com.
  2. Haz clic en Download y elige el instalador de tu sistema (Windows, macOS o Linux). En el curso se descarga la versión de Windows de 64 bits.
  3. Abre el archivo descargado para iniciar el instalador y acepta los términos y condiciones. Clic en Siguiente.
  4. Deja la ruta de instalación por defecto y el grupo de programas que sugiere. Clic en Siguiente.
  5. En las tareas adicionales marca:
    • Crear un icono en el escritorio (Create a desktop icon).
    • Agregar «Abrir con Code» al menú contextual del Explorador de Windows, para abrir archivos y carpetas del proyecto con clic derecho.
  6. Clic en Siguiente → Instalar. Al terminar, clic en Finalizar; si dejaste marcada la opción, el editor se abre solo.

Instalar las extensiones de VS Code

Prettier, Bracket Pair Colorizer 2 y ES7 React snippets
  1. Abre VS Code y entra a la vista de Extensiones: el icono de los cuadrados en la barra lateral izquierda (o Ctrl + Shift + X).
  2. Busca Prettier (con doble T) y elige la primera: Prettier - Code formatter. Clic en Install.
    Ordena la indentación y la estructura del código para que quede prolijo y con un formato estándar. No es obligatoria: si no te convence, en el engranaje de la extensión eliges Uninstall.
  3. Busca Bracket Pair Colorizer. Aparecen las versiones 1 y 2; instala la 2, que es la mejorada.
    Colorea cada par de llaves para ver dónde empieza y termina cada función, muy útil en componentes grandes.
  4. Busca ES7 e instala ES7 React/Redux/React-Native snippets.
    Con una abreviatura escribe un bloque de código completo (componentes, métodos, imports) y acelera el desarrollo.
Nota actualBracket Pair Colorizer 2 ya está obsoleta: VS Code colorea los pares de llaves por sí solo desde 2021 (ajuste editor.bracketPairColorization.enabled, activado por defecto). Si no aparece en el buscador, no hace falta instalarla. La extensión de snippets hoy se llama ES7+ React/Redux/React-Native snippets.
4

Configurar Prettier para que formatee al guardar

Dos ajustes en Settings
  1. En VS Code ve a File → Preferences → Settings (o Ctrl + ,).
  2. En el buscador de ajustes escribe format.
  3. En Editor: Default Formatter elige Prettier - Code formatter en la lista desplegable.
  4. Marca la casilla Editor: Format On Save.
  5. Cierra los ajustes. Desde ahora, cada vez que guardes (Ctrl + S o File → Save) el archivo se formatea solo: corrige la indentación y completa, por ejemplo, los punto y coma que falten.

Si prefieres editar el archivo de configuración directamente, el resultado equivale a esto en settings.json:

settings.json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true
}

Instalar Node.js

Necesario para crear el proyecto React e instalar sus módulos
  1. Busca Node en el navegador y entra a la página oficial: nodejs.org.
  2. Descarga la versión LTS (Long Term Support). Es la versión estable y probada. La otra («Current») trae las últimas características pero se recomienda la LTS.
  3. Ejecuta el instalador: Next → acepta los términos → Next.
  4. Deja la ruta por defecto y las opciones como están → Next → Install.
  5. Acepta la ventana de seguridad de Windows (Sí) y, al terminar, clic en Finish.
  6. Comprueba la instalación en una consola nueva:
CMD
node -v
npm -v
Nota actualEn el video se ve Node 14.17.4 LTS. Hoy la versión será mayor; lo importante es instalar siempre la que diga LTS. Este paso de comprobación no aparece en el video, pero confirma que node y npm quedaron disponibles.

Crear el mini proyecto «Intro JS» y verlo en el navegador

Consola de Windows, VS Code e IIS

a) Crear la carpeta y los archivos desde la consola. Abre la lupa de Windows, escribe CMD y presiona Enter.

CMD
cd \
mkdir introjs
cd introjs
copy con index.html
copy con script.js
code .
  1. cd \ lleva a la raíz del disco C: (también puedes usar cd .. varias veces).
  2. mkdir introjs crea la carpeta del proyecto y cd introjs entra en ella.
  3. copy con index.html crea un archivo vacío. Para terminarlo presiona Ctrl + Z y luego Enter. Repite con script.js.
  4. code . abre VS Code en esa carpeta. Si pregunta si confías en los autores, clic en Yes.
AclaraciónEn el audio no se oye el atajo para cerrar copy con: es Ctrl + Z y Enter. Otra forma de crear un archivo vacío es type nul > index.html.

b) Escribir la estructura HTML. En index.html escribe html y elige el snippet html:5 (o escribe ! y Tab): VS Code arma la estructura completa. Cambia el título a Intro, agrega un <h1> y enlaza el script:

introjs/index.html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Intro</title>
  </head>
  <body>
    <h1>Introducción a ECMAScript 6</h1>
    <script type="module" src="./script.js"></script>
  </body>
</html>
  • type="module" prepara el archivo para usar import y export, que se ven más adelante.
  • ./ indica que script.js está en la misma carpeta que index.html.

c) Publicarlo en IIS para abrirlo con localhost. Un script con type="module" no funciona abriendo el archivo con doble clic; necesita un servidor web. El curso usa Internet Information Services (IIS), que viene con Windows:

  1. En la lupa de Windows busca «Activar o desactivar las características de Windows» (en inglés: Turn Windows features on or off).
  2. Marca Internet Information Services y pulsa Aceptar. Espera a que se instale.
  3. En la lupa escribe IIS y abre el Administrador de Internet Information Services.
  4. Despliega el nombre del equipo → Sitios → clic derecho en Default Web Site → Agregar directorio virtual.
  5. Alias: introjs. Ruta de acceso física: C:\introjs. Clic en Aceptar.
  6. En Chrome abre http://localhost/introjs/index.html. El nombre del archivo es opcional porque index.html se abre por defecto.
  7. Debe verse el título «Introducción a ECMAScript 6». Abre la consola del navegador con F12: ahí verás los console.log de los siguientes pasos.
Alternativa más sencillaSi no quieres instalar IIS, puedes usar la extensión Live Server de VS Code (clic derecho en index.html → Open with Live Server) o ejecutar npx serve dentro de la carpeta. Funcionan igual para este mini proyecto.

Declarar variables con let y entender el scope

Todo el código de la Parte 2 va en script.js

let declara una variable cuyo valor puede cambiar durante la vida de la aplicación. Para los nombres se usa camelCase: primera palabra en minúscula y la inicial de las siguientes en mayúscula (peliculaTitulo).

  1. Crea la función setTitulo con una variable let dentro y muéstrala en consola. Llama a la función, guarda y recarga con F5.
script.js
function setTitulo() {
  let peliculaTitulo = "Terminator 2";
  console.log(peliculaTitulo);
}

setTitulo();
  1. Prueba a declarar otra vez la misma variable dentro de la función. El navegador muestra un error porque una variable let no se puede volver a declarar en el mismo bloque:
script.js · prueba que falla
function setTitulo() {
  let peliculaTitulo = "Terminator 2";
  console.log(peliculaTitulo);
  let peliculaTitulo = "Avengers"; // ❌ error
}
  1. Comenta o borra esa línea. Ahora declara una variable con el mismo nombre fuera de la función y muéstrala después de la llamada:
script.js
let peliculaTitulo = "Avengers"; // scope global

function setTitulo() {
  let peliculaTitulo = "Terminator 2"; // scope local
  console.log(peliculaTitulo);
}

setTitulo();
console.log(peliculaTitulo);

Se imprimen los dos títulos por el scope (alcance) de cada variable:

Global (todo el archivo)
peliculaTitulo = "Avengers"

Se puede usar en cualquier parte del código.

Local (dentro de setTitulo)
peliculaTitulo = "Terminator 2"

Solo existe dentro de la función y ahí tapa a la global.

8

Declarar constantes con const

Valores que no cambian
  1. Crea la función setPrecio con una constante y llámala:
script.js
function setPrecio() {
  const peliculaPrecio = 50;
  console.log(peliculaPrecio);
}

setPrecio();
  1. Intenta asignarle otro valor dentro de la función (peliculaPrecio = 60;). Aparece un error: a una constante no se le puede cambiar el valor.
script.js · prueba que falla
function setPrecio() {
  const peliculaPrecio = 50;
  console.log(peliculaPrecio);
  peliculaPrecio = 60; // ❌ error
}
  1. Comenta esa línea. Declara una constante global con el mismo nombre y muéstrala al final. El scope funciona igual que con let:
script.js
const peliculaPrecio = 20; // global

function setPrecio() {
  const peliculaPrecio = 50; // local
  console.log(peliculaPrecio);
  // peliculaPrecio = 60;
}

setPrecio();
console.log(peliculaPrecio);
¿Cuándo usar const?Para datos que no cambian mientras la app está en uso, por ejemplo el correo del usuario que inició sesión.
9

Concatenar texto con backticks

Template literals de ES6
  1. Crea la función mostrarPrecio y concatena con +, la forma clásica:
script.js
function mostrarPrecio() {
  let peliculaPrecio = 65;
  console.log("El precio es: " + peliculaPrecio);
}

mostrarPrecio();
  1. Ahora escribe lo mismo con backticks (`): encierra todo el texto entre backticks y coloca cada variable dentro de ${ }. Ya no hace falta un + por cada variable.
script.js
function mostrarPrecio() {
  let peliculaPrecio = 65;
  console.log("El precio es: " + peliculaPrecio);
  console.log(`El precio es: ${peliculaPrecio}`);
}

mostrarPrecio();
¿Dónde está el backtick?En el teclado español suele estar junto a la tecla de los corchetes y llaves (se escribe con Shift y luego espacio). Si no lo encuentras: Alt + 96 en el teclado numérico.
10

Escribir funciones flecha (arrow functions)

La forma de función que más se usa en React
  1. Comenta la función anterior con /* ... */.
  2. Declara la función como si fuera una constante: const, el nombre, =, los paréntesis de los parámetros y la flecha =>.
  3. Llámala como cualquier función y recarga el navegador.
script.js
/*
function mostrarPrecio() { ... }
*/

const mostrarPrecio = () => {
  let peliculaPrecio = 70;
  console.log(`El precio es: ${peliculaPrecio}`);
};

mostrarPrecio();

Particularidades de las funciones flecha:

  • Entre los paréntesis van los parámetros. Si hay uno solo, se pueden omitir los paréntesis.
  • Si el cuerpo es una sola instrucción, se pueden omitir las llaves. Con varias instrucciones, las llaves son obligatorias.
ejemplo · forma corta
const saludar = nombre => console.log(`Hola, ${nombre}`);

saludar("Celeste");

Recorrer un array con map

Mostrar una lista de películas

map está disponible en todos los arrays: recorre cada elemento como si fuera un bucle y ejecuta una función por cada uno.

  1. Define un array de objetos. Los corchetes [ ] crean el array y cada par de llaves { } es un objeto con sus propiedades. Los números van sin comillas y los textos entre comillas.
  2. Crea la función flecha mostrarTodas, que recibe el array como parámetro.
  3. Dentro, llama a peliculas.map() con una función flecha que recibe cada elemento (p) y lo imprime.
  4. Llama a mostrarTodas(peliculas), guarda y recarga.
script.js
let peliculas = [
  { idPelicula: 1, titulo: "Avatar" },
  { idPelicula: 2, titulo: "Terminator 2" },
  { idPelicula: 3, titulo: "Silent Hill" },
];

const mostrarTodas = (peliculas) => {
  peliculas.map((p) => console.log(p.idPelicula, p.titulo));
};

mostrarTodas(peliculas);
Por qué convieneLa función flecha dentro de map no necesita nombre ni declararse aparte: recibe el elemento p y lo usa ahí mismo. La estructura se parece a JSON, pero es un objeto de JavaScript.

Primeros pasos con React

12

Entender qué es React

Contexto antes de programar
  • Es una librería de JavaScript para construir interfaces de usuario (front end), creada por Facebook.
  • Usa todas las novedades de ECMAScript más herramientas propias que simplifican el trabajo: modificar el DOM a mano con JavaScript es tedioso y React lo resuelve con componentes, hooks de estado, de contexto y de referencia, y componentes de terceros.
  • La documentación oficial y su tutorial están en react.dev (antes reactjs.org). Conviene consultarla ante cualquier duda.
  • En el curso se trabaja con componentes funcionales.

Crear el primer componente: Peliculas

Limpieza, componente funcional, Fragment y Virtual DOM

a) Limpiar el proyecto. En src selecciona y borra (tecla Supr) los archivos que no se usarán, y crea las carpetas del componente:

src/ ├── App.css ├── App.js ├── App.test.js ├── index.css ├── logo.svg ├── reportWebVitals.js ├── setupTests.js ├── index.js └── components/ └── Pelicula/ └── Peliculas.jsx
  1. En index.js borra los import de los archivos eliminados, el componente <App /> y las líneas finales de reportWebVitals. Guarda.
  2. Clic derecho en src → New Folder → components. Dentro, otra carpeta Pelicula.
  3. Dentro de Pelicula: New File → Peliculas.jsx. Las extensiones .js y .jsx son válidas; .jsx ayuda a que el editor reconozca el componente.

b) Escribir el componente.

src/components/Pelicula/Peliculas.jsx
import React from "react";

const Peliculas = () => {
  return (
    <div>
      <h2>Películas</h2>
    </div>
  );
};

export default Peliculas;
  1. Imports arriba: todo componente importa React con import React from "react";.
  2. Definición: una función flecha cuyo nombre empieza con mayúscula. Así React la reconoce como componente. Es un componente funcional. Los componentes de clase existen, pero el curso no los usa porque requieren más código y React se orienta a los funcionales.
  3. return: devuelve el HTML (JSX) que el componente insertará donde se use.
  4. export default: sin exportarlo, ningún otro archivo puede importarlo y se produce un error.

c) Un único elemento padre. Si agregas un segundo <div> al mismo nivel, aparece un error. Se soluciona envolviendo todo en un Fragment, una etiqueta vacía <> </>:

ErrorJSX expressions must have one parent element (la expresión JSX debe tener un único elemento padre).
src/components/Pelicula/Peliculas.jsx
import React from "react";

const Peliculas = () => {
  return (
    <>
      <div>
        <h2>Películas</h2>
      </div>
      <div>Película contenido</div>
    </>
  );
};

export default Peliculas;

d) Mostrar el componente en index.js. Impórtalo con la ruta relativa (sin extensión) y escríbelo como etiqueta con la P mayúscula, igual que se exportó:

src/index.js
import React from "react";
import ReactDOM from "react-dom/client";
import Peliculas from "./components/Pelicula/Peliculas";

const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(
  <React.StrictMode>
    <Peliculas />
  </React.StrictMode>
);
Diferencia con el videoEn el video, index.js usa la forma de React 17: import ReactDOM from "react-dom"; y ReactDOM.render(<React.StrictMode><Peliculas /></React.StrictMode>, document.getElementById("root"));. Los proyectos creados hoy traen React 18 o 19, que usa createRoot como en el bloque de arriba. Deja la forma que traiga tu proyecto y solo cambia los imports y el componente.
  1. Ejecuta npm start. En el navegador se ven el título «Películas» y el texto «Película contenido».

e) Virtual DOM y Webpack.

  • Lo que va dentro del return parece HTML, pero es JSX. El Virtual DOM lo procesa y genera el HTML final dentro de un archivo JavaScript que el navegador interpreta.
  • Por eso el JSX es estricto: toda etiqueta debe cerrarse y los atributos deben escribirse como los reconoce React. Un HTML común perdona una etiqueta sin cerrar; React no.
  • Webpack compila los componentes y valida que estén bien escritos. Si quitas un </div> y guardas, la terminal marca el error en rojo con una flecha (JSX incompleto / etiqueta sin cerrar).
