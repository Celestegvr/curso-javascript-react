Parte 1

Instalación de herramientas

Se prepara el entorno: un editor de código con extensiones útiles y Node.js para trabajar con React.

1Instalar Visual Studio Code

VS Code es uno de los editores más usados. Trae IntelliSense (autocompletado), herramientas de depuración y una terminal integrada.

  1. Buscar vs code en Google y entrar a la página oficial: code.visualstudio.com.
  2. Hacer clic en Download y elegir el instalador del sistema. En el curso se descarga el de Windows de 64 bits.
  3. Abrir el archivo descargado, aceptar los términos y pulsar Siguiente.
  4. Dejar la ruta de instalación por defecto y el grupo de programas sugerido.
  5. En las tareas adicionales marcar Crear un icono en el escritorio y Agregar «Abrir con Code» al menú contextual del Explorador de Windows.
  6. Pulsar Instalar y, al terminar, Finalizar. El editor se abre solo.

Para comprobar que quedó instalado (junto con Node.js, del paso 5) se pueden pedir las versiones desde la consola:

2Tener a mano los atajos de teclado

La clase incluye un PDF con todos los atajos de VS Code (también está en el menú Help → Keyboard Shortcuts Reference). Los que se usan en el curso son:

  • Ctrl + S: guardar el archivo (con Prettier configurado, también lo formatea).
  • Ctrl + Ñ (teclado español) o Ctrl + ` (teclado inglés): abrir la terminal integrada.
  • Ctrl + rueda del ratón: agrandar la letra en la consola de Windows.
  • F5 en el navegador: recargar la página. F12: abrir las herramientas de desarrollo y la consola.

3Instalar las extensiones de VS Code

  1. Abrir la vista de Extensiones: el icono de los cuadrados en la barra lateral (o Ctrl + Shift + X).
  2. Buscar Prettier e instalar Prettier - Code formatter. Ordena la indentación y la estructura del código.
  3. Buscar Bracket Pair Colorizer e instalar la versión 2. Colorea cada par de llaves para ver dónde empieza y termina cada función.
  4. Buscar ES7 e instalar ES7+ React/Redux/React-Native snippets. Con una abreviatura escribe bloques de código completos (componentes, imports, etc.).

Las mismas extensiones también se pueden instalar desde la consola con code --install-extension. Así las instalé y luego comprobé la lista:

Nota actualBracket Pair Colorizer 2 está obsoleta: desde 2021 VS Code colorea los pares de llaves por sí solo (ajuste editor.bracketPairColorization.enabled). Todavía se puede instalar, pero no es necesaria.

4Configurar Prettier para que formatee al guardar

  1. Ir a File → Preferences → Settings (o Ctrl + ,).
  2. Escribir format en el buscador de ajustes.
  3. En Editor: Default Formatter elegir Prettier - Code formatter.
  4. Marcar Editor: Format On Save.
  5. Cerrar los ajustes. Cada vez que se guarda con Ctrl + S el archivo se formatea solo.

Esos dos ajustes quedan escritos en un archivo settings.json. Yo los guardé solo para este proyecto, en .vscode/settings.json, para no cambiar el formato de mis otros proyectos:

5Instalar Node.js

Node.js hace falta para crear el proyecto React e instalar sus módulos con npm.

  1. Buscar Node y entrar a la página oficial: nodejs.org.
  2. Descargar la versión LTS (soporte a largo plazo): es la estable y probada. La otra, «Current», trae lo más nuevo, pero se recomienda la LTS.
  3. Ejecutar el instalador: Next, aceptar los términos, dejar la ruta y las opciones por defecto e Install.
  4. Aceptar la ventana de seguridad de Windows y pulsar Finish.
  5. Comprobar en una consola nueva con node -v y npm -v (ver la figura del paso 1).
Nota actualEn el video se instala Node 14.17.4 LTS. En mi equipo está la versión 24.20.0; lo importante es elegir siempre la que dice LTS.
Parte 2

Introducción a JavaScript ECMAScript 6

Un mini proyecto para repasar las novedades de ES6 que después se usan en React. Todos los ejemplos se escriben en script.js y el resultado se ve en la consola del navegador (F12).

6Crear el mini proyecto «introjs» y verlo en el navegador

a) Crear la carpeta y los archivos desde la consola. En la lupa de Windows escribir CMD y pulsar Enter.

  1. Ir a la carpeta donde se guardará el proyecto (en el video, cd \ lleva a la raíz del disco C:).
  2. mkdir introjs crea la carpeta y cd introjs entra en ella.
  3. copy con index.html crea el archivo. Se termina con Ctrl + Z y Enter. Repetir con script.js.
  4. code . abre VS Code en esa carpeta. Si pregunta si se confía en los autores, pulsar Yes.

b) Escribir la estructura HTML. En index.html escribir html y elegir el snippet html:5 (o ! y Tab). Cambiar el título a «Intro», agregar un h1 y enlazar el script con type="module" (prepara el archivo para import y export). El ./ indica que script.js está en la misma carpeta.

c) Abrirlo con un servidor web. Un script con type="module" no funciona abriendo el archivo con doble clic. En el curso se usa Internet Information Services (IIS):

  1. Buscar «Activar o desactivar las características de Windows», marcar Internet Information Services y pulsar Aceptar.
  2. Abrir el Administrador de IIS (buscar IIS en la lupa).
  3. En Sitios, clic derecho sobre Default Web Site → Agregar directorio virtual. Alias: introjs. Ruta física: la carpeta del proyecto.
  4. Abrir http://localhost/introjs/index.html en Chrome. El nombre del archivo es opcional porque index.html se abre por defecto.
Lo que hice yoNo activé IIS en mi equipo. Usé un servidor local equivalente (la extensión Live Server de VS Code o python -m http.server hacen lo mismo), por eso en las capturas la dirección es localhost:5530/introjs/. El resultado es idéntico.

7Declarar variables con let y entender el scope

let declara una variable cuyo valor puede cambiar. Los nombres se escriben en camelCase: la primera palabra en minúscula y la inicial de las siguientes en mayúscula (peliculaTitulo).

  1. Crear la función setTitulo con una variable let, mostrarla con console.log, llamar a la función, guardar y recargar con F5.
  1. Probar a declarar otra vez la misma variable dentro de la función. VS Code la subraya y el navegador muestra un error: una variable let no se puede volver a declarar en el mismo bloque.
  1. Comentar esa línea y declarar una variable con el mismo nombre fuera de la función. Mostrarla después de llamar a la función.

Se ven los dos títulos por el scope (alcance) de cada variable: la de afuera es global y se puede usar en todo el archivo; la de adentro es local, solo existe dentro de setTitulo y ahí tapa a la global.

8Declarar constantes con const

  1. Crear la función setPrecio con const peliculaPrecio = 50, mostrarla y llamar a la función.
  2. Probar a asignarle otro valor (peliculaPrecio = 60;). Aparece un error: a una constante no se le puede cambiar el valor.
  1. Comentar esa línea. Declarar una constante global con el mismo nombre (valor 20) y mostrarla al final. El scope funciona igual que con let.
¿Cuándo usar const?Para datos que no cambian mientras la aplicación está en uso, por ejemplo el correo del usuario que inició sesión.

9Concatenar texto con backticks

  1. Crear la función mostrarPrecio y concatenar con +, la forma clásica: "El precio es: " + peliculaPrecio.
  2. Escribir lo mismo con backticks: todo el texto entre y cada variable dentro de ${ }. Ya no hace falta un +` por cada variable.
¿Dónde está el backtick?En el teclado español suele estar junto a la tecla de los corchetes y llaves. Si no aparece: Alt + 96 en el teclado numérico.

10Escribir funciones flecha (arrow functions)

  1. Comentar la función anterior con / ... /.
  2. Declararla como constante: const mostrarPrecio = () => { ... };
  3. Llamarla como cualquier función y recargar el navegador.
  • Entre los paréntesis van los parámetros. Si hay uno solo, se pueden omitir los paréntesis.
  • Si el cuerpo es una sola instrucción, se pueden omitir las llaves. Con varias instrucciones son obligatorias.

11Recorrer un array con map

map está disponible en todos los arrays: recorre cada elemento como un bucle y ejecuta una función por cada uno.

  1. Definir el array peliculas: los corchetes crean el array y cada par de llaves es un objeto con idPelicula y titulo. Los números van sin comillas y los textos entre comillas.
  2. Crear la función flecha mostrarTodas, que recibe el array como parámetro.
  3. Dentro, llamar a peliculas.map() con una función flecha que recibe cada elemento (p) y lo imprime.
  4. Llamar a mostrarTodas(peliculas), guardar y recargar.
Por qué convieneLa función flecha dentro de map no necesita nombre ni declararse aparte: recibe el elemento y lo usa ahí mismo. La estructura se parece a JSON, pero es un objeto de JavaScript.
Parte 3

Primeros pasos con React

Se crea el proyecto peliculas_spa (Single Page Application) y su primer componente funcional.

12Entender qué es React

  • Es una librería de JavaScript para construir interfaces de usuario (front end), creada por Facebook. Su documentación oficial está en react.dev.
  • Usa las novedades de ECMAScript más herramientas propias: componentes, hooks de estado, de contexto y de referencia, y componentes de terceros. Modificar el DOM a mano con JavaScript es tedioso; React lo simplifica.
  • El curso trabaja con componentes funcionales.

13Crear el proyecto React

  1. Abrir CMD y entrar a la carpeta de trabajo (en el video: cd \, mkdir demoreact y cd demoreact).
  2. Ejecutar npx create-react-app peliculas_spa. Tarda unos minutos (en mi equipo, unos 8).
  3. Entrar con cd peliculas_spa y abrir el proyecto con code .. Confiar en los autores (Yes).
Nota actualCreate React App fue declarado obsoleto en 2025 y lo avisa al empezar (línea amarilla), pero sigue funcionando: instaló React 19 y el proyecto compila bien. Una alternativa actual es Vite: npm create vite@latest.

14Ejecutar la app y entender cómo funciona

  1. Abrir la terminal de VS Code (Ctrl + Ñ) y ejecutar npm start. Se abre el navegador en http://localhost:3000.

El recorrido que hace la aplicación para mostrar esa página:

  1. public/index.html tiene un div vacío con id="root".
  2. src/index.js importa los componentes y los dibuja dentro de root con render. React.StrictMode viene por defecto y activa el modo estricto.
  3. src/App.js es el componente que retorna el HTML de la página: el logo, el texto y el enlace. Para usarlo se escribe como etiqueta: <App />, y al importarlo no hace falta la extensión .js.
Diferencia con el videoEn el video index.js usa la forma de React 17: ReactDOM.render(<App />, document.getElementById("root")). Mi proyecto trae React 19, que usa ReactDOM.createRoot(...) y root.render(...). La idea es la misma.
  1. Quitar el logo en App.js y guardar: el navegador se actualiza solo, sin F5. Después dejar el archivo como estaba.

Todo lo que se escribe en React termina convertido en JavaScript, el lenguaje que entienden todos los navegadores.

b) Crear el componente. Clic derecho en src → New Folder → components; dentro, la carpeta Pelicula y el archivo Peliculas.jsx (las extensiones .js y .jsx son válidas; .jsx ayuda al editor a reconocer el componente).

  • Imports arriba: todo componente importa React con import React from "react";.

Código en GitHub y Vercel

El código de los dos proyectos se subió a GitHub y se publicó en Vercel.

16Compilar y publicar el código

  1. Comprobar que la app compila para producción con npm run build.
  2. Subir la carpeta del curso a GitHub: https://github.com/Celestegvr/curso-javascript-react.
  3. En Vercel, Add New → Project, importar el repositorio y pulsar Deploy. El archivo vercel.json le indica cómo compilar peliculas_spa y copia introjs dentro del sitio.
  4. Cada vez que se sube un cambio a la rama main, Vercel vuelve a publicar el sitio.
vercel.json
{
  "installCommand": "cd peliculas_spa && npm install",
  "buildCommand": "cd peliculas_spa && npm run build && cp -r ../introjs build/introjs",
  "outputDirectory": "peliculas_spa/build"
}
